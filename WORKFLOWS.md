# Workflows PCS

## Création
Authentification → catégorie → description → médias optionnels → localisation → vérification → soumission → référence → notification.

## Traitement
Réception → tri/modération → attribution → prise en charge → traitement → résolution ou rejet.

## Doublons
Des signalements proches pourront être rapprochés selon localisation, catégorie et période. L’automatisation avancée est hors MVP.

## Réouverture
Une procédure contrôlée pourra rouvrir un signalement résolu si le problème persiste.
