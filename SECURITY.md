# Sécurité PCS

- Supabase Auth pour l’authentification.
- Autorisation côté serveur/base de données.
- RLS sur toutes les données exposées.
- Principe du moindre privilège.
- Contrôle des types et tailles de fichiers.
- Buckets privés lorsque nécessaire.
- URLs signées pour les fichiers privés.
- Rate limiting et anti-spam.
- Minimisation des données personnelles.
- Journalisation des actions sensibles.
- Aucun secret ou service-role key dans le dépôt.
