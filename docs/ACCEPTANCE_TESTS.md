# Tests d’acceptation MVP

## AT-001 Création
Un utilisateur authentifié crée un signalement valide et obtient une référence unique.

## AT-002 Localisation
Le signalement conserve une position valide ou une localisation descriptive lorsqu’une position précise n’est pas disponible.

## AT-003 Confidentialité
Un citoyen ne peut lire les données privées du signalement d’un autre citoyen.

## AT-004 Agent
Un agent autorisé peut traiter les signalements de son périmètre et aucun autre sans permission appropriée.

## AT-005 Historique
Une transition de statut crée une entrée d’historique.

## AT-006 Médias
Un fichier non autorisé est refusé et un fichier valide est stocké selon les règles de sécurité.

## AT-007 Administration
Un administrateur autorisé peut gérer les catégories et consulter les audits.

## AT-008 RLS
Les tests d’accès croisé entre rôles échouent correctement lorsque l’accès est interdit.

## AT-009 Notification
Une notification est créée pour les événements métier configurés.

## AT-010 Résolution
La résolution est visible au citoyen selon les règles de publication et conserve les éléments d’audit nécessaires.
