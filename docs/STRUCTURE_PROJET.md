# Structure cible

La structure exacte dépendra du framework retenu dans Lovable, mais doit conserver des frontières claires entre:

- pages/routes;
- composants UI;
- logique métier;
- accès Supabase;
- validations;
- types;
- hooks;
- services;
- tests.

La documentation ne doit pas imposer une structure artificielle avant inspection du projet généré.
