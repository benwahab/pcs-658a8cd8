# Environnements PCS

## Development
Travail quotidien et expérimentation contrôlée.

## Staging
Validation avant production avec configuration proche de la production.

## Production
Environnement réel, protégé et soumis aux procédures de déploiement.

## Règle
Les clés et URLs de chaque environnement doivent être stockées dans les variables de configuration appropriées et jamais dans le code source.
